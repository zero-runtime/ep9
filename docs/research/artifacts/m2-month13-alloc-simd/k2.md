How each count is made (patch hooks):

| Count | Hook |
|---|---|
| cells and bytes by kind | `Heap::alloc` and `Heap::alloc_shape` (rounded size), per kind id |

| chain rule | the f-design L1 rule: walk the [[Prototype]] chain from `proto`; at each object read the own `constructor`; a bytecode constructor that is not derived adds the names of its `this.<name> =` stores (the scan in escape mode: a leave of `this` marks `escaped` and the scan goes on); stop at a host function, a dictionary object, 8 levels. `n = chain names + proto extra (as today) + ESCAPE_SLACK (if escaped)`; capacity = n if n > 8, else today's |
| adds by field index | `props::own_add` (the generic add) and the IC add hit in `ic::store_with` |
| named-load field kind | `ic::load_with` (the aarch64 hit path of every named load) |
| context (caller split) | a guard in `slow::get_named`, `slow::set_named`, `keyed_ic::cold_get`, the `SetKeyedProperty` cold body, `for_in_keys`, `for_in_has` |
| SHAPEs | `shape::new_shape` |
| for-in, `new Array`, element growth | `property::for_in_keys` / `for_in_has`; `natives::array_constructor`; `object::store_element_slow` |

## 6. Not verified

- The class of an object is `proto.constructor`. For the TS `__extends` classes this is the constructor that `new` ran (each prototype has its own `constructor`). A class whose prototype has no own `constructor` reads as "(none)" (851 objects).
- The chain rule is simulated at the first add or growth of a class, not at its first construct. The prototype state can differ (I).
- The simulation keeps the growth rule max(need, 2 x old, 4) and the object size 24 + 8 x (fixed + capacity). The object bytes use the main capacity of each class.
- Bytes, cells and hits are counts (M). The time estimate of L1 uses the f-design unit prices (G).
- The scan in escape mode reads every name that the code stores on `this`, also on paths that do not run. A name that is not stored in a run takes a slot (I).
